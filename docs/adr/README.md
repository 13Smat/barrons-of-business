# Decision records

One ADR per accepted decision. Include the alternatives and why they lost. Open a GitHub issue titled `Decision: ...` first. An ADR records the outcome after the deciding human comments, and after you close that issue.

The engine and stack are open. No ADR in this list chooses them. The next free number is 0003.
